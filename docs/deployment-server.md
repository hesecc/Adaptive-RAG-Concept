## 运维与回退

所有命令显式指定本项目 Compose、env 与项目名。部署及额外 CLI 写入须与备份使用同一维护锁。首次上线和后续操作不运行全局 prune、不删除卷，不修改其他项目的源码、秘密或持久数据。

手动冷备只停止本项目 API，备份数据、配置与私密材料后恢复原运行状态；恢复检查仅写新的受控隔离目录，不覆盖生产。操作和回退命令见 [deploy/README.md](../deploy/README.md)。备份包含秘密，目前保留于同机，仍需制定异机加密副本、保留周期和自动调度。
